# Brazilian-E-Commerce Data Analysis
This project offers a detailed analysis of a Brazilian e-commerce dataset, incorporating exploratory data analysis (EDA) to identify customer purchasing trends, demand patterns, and product-specific insights. Additionally, it includes sentiment analysis of product reviews using natural language processing (NLP), along with machine learning models to predict key outcomes.

## Data Source
Source: Brazilian e-commerce dataset from Kaggle.
[Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Contents: Customer, product, and transaction data 

Features: Purchase time, product category, review scores, and text reviews.

## Project Objectives
Analyze customer purchasing behaviors to identify key demand patterns.
Leverage natural language processing (NLP) to assess customer sentiment through review analysis.
Implement machine learning techniques to predict customer behavior and product trends.

## Framework
**Data Cleaning:** Prepare the dataset by addressing missing values, ensuring correct data types, and eliminating irrelevant information.

**Exploratory Data Analysis:** Identify trends in customer behavior, peak demand periods, and product popularity.

**NLP Analysis:** Perform tokenization, sentiment analysis, and categorize review text for deeper insights.

**Machine Learning Models:** Select and evaluate models for predictive analysis using customer and transaction data.
